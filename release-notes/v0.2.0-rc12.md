Test version of the new `nvidia-prolapse` mode: an open-source NVIDIA driver running right inside Android.

## What's new

- **Faster.** 3DMark Wild Life Extreme on an RTX 5090: 432 FPS in rc11, 475 FPS now (+10 %). NVIDIA's own
  driver gets 508. The gains come from the shader compiler, ZCULL (early depth culling), an async compute queue
  and better GPU dispatch settings. Other GPUs were not measured.
- **Async compute queue** for Vulkan apps on RTX 20, 30, 40 and 50 and Titan V. On RTX 30 and newer, compute and
  graphics run on the GPU at the same time. GTX 10 doesn't get it: there it lost graphics work in our tests.
- **`glibc-shim` mode for package users:** `sudo waydroid-nvidia-setup --mode glibc-shim` runs your own NVIDIA
  driver inside Android. Works on drivers 550 to 615, open or closed kernel module. Driver 535 is refused: it
  can't share fences with Android.
- **Known limitation:** on drivers 550 to 560 and 580, `glibc-shim` works around two NVIDIA driver bugs, which
  may add some frame latency.

## Install or update

```sh
curl -fsSL https://raw.githubusercontent.com/Shiro836/waydroid-nvidia/public-test/packaging/install.sh | sudo bash
sudo waydroid-nvidia-setup
waydroid session start
```

For Google apps on a new install, use `sudo waydroid-nvidia-setup -s GAPPS`. Supported GPUs, drivers and known
issues are in the [README](https://github.com/Shiro836/waydroid-nvidia/tree/public-test#readme).
