Test version of the new `nvidia-prolapse` mode: an open-source NVIDIA driver running right inside Android.

## What's new

- **Faster on RTX 50 series.** 3DMark Wild Life Extreme on an RTX 5090 (driver 615.78.08), all runs in the same
  session: rc11 428.1 FPS, this build 464.5 FPS (+8.5 %). NVIDIA's own driver inside Android scored 493.5 FPS.
  The gains come from:
  - the shader compiler, which now produces faster code for loops and, on RTX 50 series, for texture fetches;
  - an async compute queue on RTX 50 series (next item);
  - compute dispatches that now use the same GPU settings as NVIDIA's driver.

  Other GPUs were not measured for this release.
- **Async compute queue on RTX 50 series.** Vulkan apps get a second queue family for compute and transfers whose
  work runs on the GPU at the same time as the graphics queue's, as with NVIDIA's own driver. Other GPUs keep the
  graphics and transfer queues only for now.
- **glibc-shim mode: 3DMark Wild Life Extreme no longer crashes when it starts.**

## Install or update

```sh
curl -fsSL https://raw.githubusercontent.com/Shiro836/waydroid-nvidia/public-test/packaging/install.sh | sudo bash
sudo waydroid-nvidia-setup
waydroid session start
```

For Google apps on a new install, use `sudo waydroid-nvidia-setup -s GAPPS`. Updating from an earlier rc is the same
commands. Supported GPUs, drivers and known issues are in the
[README](https://github.com/Shiro836/waydroid-nvidia/tree/public-test#readme).
