First release of the `nvidia-prolapse` mode: an open-source NVIDIA driver running right inside Android, now the
default. Venus from v0.1 stays available as a mode.

## What's new since v0.1.2

- **New default mode `nvidia-prolapse`:** Mesa's open NVK driver inside Android, using only the NVIDIA kernel module
  from your system. 475 FPS in 3DMark Wild Life Extreme on an RTX 5090 (NVIDIA's own driver: 508).
- **No shader stutter:** Minecraft's first item switch takes ~0.2 s (Venus: 1.8 s).
- **Hardware video decode:** H.264, HEVC, VP9 and AV1 on RTX 20 and newer.
- **Closed kernel module works too.**
- **Older GPUs:** the default mode also covers GTX 10, Titan V and GTX 900 (Venus: RTX 20 and newer).
- **Second mode `glibc-shim`:** NVIDIA's own driver inside Android. Switch with
  `sudo waydroid-nvidia-setup --mode glibc-shim` (or `--mode venus`).
- **Installer for any systemd distro**, Fedora with SELinux included. `waydroid-nvidia-setup` tests the driver on
  your GPU before it installs our Android vendor image, and keeps the official one as a backup.
- **App windows resize Android** without multi-window mode (#35, thanks @hyzor).
- **Venus mode:** real NV12 buffers for video and camera (#16), and a limit on how fast one app can allocate GPU
  memory (thanks @The-JimmyDev).

Supported GPUs, drivers and known issues are in the [README](https://github.com/Shiro836/waydroid-nvidia#readme).

## Install or update

On Arch, update `waydroid-nvidia-bin` from the AUR (it replaces `waydroid`). Elsewhere the installer does not
overwrite files of a distro package, so remove your distro's `waydroid` package first, then:

```sh
curl -fsSL https://raw.githubusercontent.com/Shiro836/waydroid-nvidia/main/packaging/install.sh | sudo bash
sudo waydroid-nvidia-setup
waydroid session start
```

For Google apps on a new install, use `sudo waydroid-nvidia-setup -s GAPPS`.
