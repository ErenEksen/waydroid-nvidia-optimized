Test version of the new `nvidia-prolapse` mode: an open-source NVIDIA driver running right inside Android.

## What's new

- **Video: resolution changes no longer stop playback.** When a video switched to a higher resolution than the
  decoder was set up for (YouTube does this when it raises the quality), hardware decoding failed. The decoder now
  finishes the frames it has, restarts at the new size and carries on, the way Android's own decoders do.
- **Video: HDR information reaches apps.** For HDR10 HEVC and AV1 videos, the mastering-display and brightness
  information in the stream is now passed to Android, so apps can see it's an HDR video.
- **Video: some VP9 videos no longer stop with an error.** VP9 videos that turn segmentation off at a key frame and
  back on later now decode correctly.
- **3DMark Wild Life Extreme no longer crashes when you run the test a second time.** On the second run the app
  creates a texture view that Vulkan doesn't allow. NVIDIA's own driver accepts it, ours aborted the app. Ours now
  accepts it too and logs a warning. Other invalid views of that kind now return an error to the app instead of
  crashing it.

## Install or update

```sh
curl -fsSL https://raw.githubusercontent.com/Shiro836/waydroid-nvidia/public-test/packaging/install.sh | sudo bash
sudo waydroid-nvidia-setup
waydroid session start
```

For Google apps on a new install, use `sudo waydroid-nvidia-setup -s GAPPS`. Updating from an earlier rc is the same
commands. Supported GPUs, drivers and known issues are in the
[README](https://github.com/Shiro836/waydroid-nvidia/tree/public-test#readme).
