Test version of the new `nvidia-prolapse` mode: an open-source NVIDIA driver running right inside Android.

## What's new

- **First install works.** On a machine without Waydroid, `sudo waydroid-nvidia-setup` used to download Android and
  then stop with "vendor.img is not the nvidia-prolapse vendor image". It now finishes the whole install. If you run
  `waydroid init` yourself, it completes too and tells you to run `sudo waydroid-nvidia-setup` before Waydroid starts.
- **Google apps right away.** `sudo waydroid-nvidia-setup -s GAPPS` installs Android with Google apps on a fresh
  install. On an existing install the setup tells you how to switch.
- **ETC2 textures work in Vulkan apps.** Android guarantees ETC2 texture compression to every Vulkan app, but NVIDIA
  desktop GPUs don't have it in hardware. We now decode it on the GPU, the same way we already handle ASTC. Fixes
  Chrome's tab strip turning white after switching back to it, and helps games that ship ETC2 textures.

## Install or update

```sh
curl -fsSL https://raw.githubusercontent.com/Shiro836/waydroid-nvidia/public-test/packaging/install.sh | sudo bash
sudo waydroid-nvidia-setup
waydroid session start
```

For Google apps on a new install, use `sudo waydroid-nvidia-setup -s GAPPS`. Updating from an earlier rc is the same
commands. Supported GPUs, drivers and known issues are in the
[README](https://github.com/Shiro836/waydroid-nvidia/tree/public-test#readme).
