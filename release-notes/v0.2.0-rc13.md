Test version of the new `nvidia-prolapse` mode: an open-source NVIDIA driver running right inside Android.

## What's new

- **Fixed:** GPU crash (Xid 32) in Vulkan apps on RTX 20, 30, 40, 50 and Titan V, from rc12's async compute queue.
- **Fixed:** Android display freezes when opening or switching apps (#38).
- **App windows resize Android** without multi-window mode, instead of scaling with black bars (#35, thanks @hyzor).

## Install or update

```sh
curl -fsSL https://raw.githubusercontent.com/Shiro836/waydroid-nvidia/public-test/packaging/install.sh | sudo bash
sudo waydroid-nvidia-setup
waydroid session start
```

For Google apps on a new install, use `sudo waydroid-nvidia-setup -s GAPPS`. Supported GPUs, drivers and known
issues are in the [README](https://github.com/Shiro836/waydroid-nvidia/tree/public-test#readme).
