Test version of the new `nvidia-prolapse` mode: an open-source NVIDIA driver running right inside Android.

## What's new

- **No more shader stutter.** Games no longer freeze for a second or more the first time they show something new.
  In Minecraft, switching to a new item froze for 1.5 s; now it takes about 0.2 s, and about 0.1 s on later launches,
  because compiled shaders are now kept per app.
- **ANGLE uses the right settings for our driver.** It mistook our open-source driver for an old proprietary NVIDIA
  driver and applied workarounds meant for that. Fixing this is what removed most of the stutter.
- **Native GL (`--native-gl on`)** also keeps compiled shaders and compiles them in the background.

## Install or update

```sh
curl -fsSL https://raw.githubusercontent.com/Shiro836/waydroid-nvidia/public-test/packaging/install.sh | sudo bash
sudo waydroid-nvidia-setup
waydroid session start
```

Updating from rc2 is the same two commands. Supported GPUs, drivers and known issues are in the
[README](https://github.com/Shiro836/waydroid-nvidia/tree/public-test#readme).
