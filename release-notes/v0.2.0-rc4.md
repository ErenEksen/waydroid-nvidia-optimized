Test version of the new `nvidia-prolapse` mode: an open-source NVIDIA driver running right inside Android.

## What's new

- **Resizing the Waydroid window works like in stock Waydroid again.** Android's screen now takes the window's size
  instead of showing a cropped picture, without the SurfaceFlinger crash that stock Waydroid can hit when it resizes.
  ([#23](https://github.com/Shiro836/waydroid-nvidia/issues/23))
- **Wrong colours in ARM games with native GL fixed.** In games running through ARM translation, some effects were drawn
  with the wrong colour channels (for example a white dress turning solid red in Punishing: Gray Raven).
  ([#24](https://github.com/Shiro836/waydroid-nvidia/issues/24))

## Install or update

```sh
curl -fsSL https://raw.githubusercontent.com/Shiro836/waydroid-nvidia/public-test/packaging/install.sh | sudo bash
sudo waydroid-nvidia-setup
waydroid session start
```

Updating from an earlier rc is the same two commands. Supported GPUs, drivers and known issues are in the
[README](https://github.com/Shiro836/waydroid-nvidia/tree/public-test#readme).
