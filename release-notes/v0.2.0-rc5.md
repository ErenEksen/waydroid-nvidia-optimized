Test version of the new `nvidia-prolapse` mode: an open-source NVIDIA driver running right inside Android.

## What's new

- **Video in games and apps plays correctly and smoothly.** Some games (for example the story videos in Punishing: Gray
  Raven) showed green stripes instead of the video, and after that was fixed they still stuttered. Both are fixed: the
  video is decoded on the GPU and handed to the app in the format it expects, from memory the CPU can read quickly
  (about 30× faster than before).
- **Android's own video decoder no longer crashes** on videos wider than about 1360 pixels in these apps.

## Install or update

```sh
curl -fsSL https://raw.githubusercontent.com/Shiro836/waydroid-nvidia/public-test/packaging/install.sh | sudo bash
sudo waydroid-nvidia-setup
waydroid session start
```

Updating from an earlier rc is the same two commands. Supported GPUs, drivers and known issues are in the
[README](https://github.com/Shiro836/waydroid-nvidia/tree/public-test#readme).
